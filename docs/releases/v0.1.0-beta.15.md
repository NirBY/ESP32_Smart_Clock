## Downloads and installation

Use the final STL ZIP for the enclosure. Print white PLA for the tested 0.6 mm
front diffuser. Read the included guide: the lid's two concealed inserts need
a pause after 4.05 mm using 0.15 mm layers, including the first layer.

For an existing personalized clock, compile the YAML with your own secrets and
upload via ESPHome. Public firmware binaries contain example configuration;
flashing them replaces your Wi-Fi/API settings. The separately named Bluetooth
speaker and hardware-test binaries replace the normal smart-clock firmware.

The countdown survives network loss but not a reboot. Music uses the current
16 kHz mono pipeline and requires an HA/Music Assistant source. Generic Google
Home timers are not automatically synchronized. Exact AliExpress product-to-part
mapping is still unverified; see the shopping checklist rather than assuming a
listing is the correct variant.

The creator supplied physical assembly photos; the exact latest insert-pause
workflow has not been independently verified. Promotional retouches are labeled
separately from real photographs and STL-generated CAD views.

## Print configuration

An editable Ender-3 V3 KE / 0.4 mm / white PLA 3MF is attached with all three parts, 0.15 mm layers, three walls, 20% gyroid and the required insert pause after 4.05 mm. Slice-checked (about 6 h 4 min, 90 g), not physically printed. Re-slice and verify the pause before use.
