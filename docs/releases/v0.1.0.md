# Smart Clock 0.1.0

First stable release following the 0.1.0 beta series. ESPHome is pinned to 2026.10.1, incorporating the upgrade proposed in PR #10 and revalidated with this release.

- Windows: open **SmartClock-Windows-x64.exe**. The small online installer downloads its checksum-pinned runtime automatically; keep the runtime ZIP attached to this release available for setup.
- macOS: open **SmartClock-macOS.dmg**, then **Smart Clock Setup**. One DMG supports Apple Silicon and Intel.
- No separate Python, Java, Git, ESPHome, Homebrew or Xcode installation is required. Internet is needed for initial setup, compiler tools, updates and driver downloads. Packages are unsigned; Windows/macOS may ask you to approve opening them. Mac USB bridges may need a vendor driver as described in the installation guide.

The desktop app provides a Wi-Fi/Home Assistant settings form, firmware update checks, personalized builds and USB/OTA installation. Find USB and automatic scanning replace disconnected serial ports after a cable move without clearing the field. A valid connected selection or network target is retained. Total estimated progress reaches 100% only after success. Interrupted or incorrect downloads are retried and verified while preserving existing settings and installations.

Firmware adds day/night brightness schedules, a Home Assistant time-range editor, independent selectable alarm/hourly/timer/reminder/volume sounds and sound-test buttons. Large clock/countdown digits have improved spacing and readability. Timer, alarm and Home Assistant update behavior include fixes from the beta series.

Release validation checks packaged GUI and firmware files against the release checkout, validates runtime hashes and installer URLs, tests download failures/recovery, installs and compiles on Windows and both Mac architectures, and builds all three firmware variants. **release-provenance.json** identifies the commit and asset hashes. Public firmware binaries use example credentials; use the desktop app for your own Wi-Fi and Home Assistant settings.

See the [installation guide](https://github.com/NirBY/ESP32_Smart_Clock/blob/v0.1.0/docs/wiki/Desktop-App.md), [brightness dashboard setup](https://github.com/NirBY/ESP32_Smart_Clock/blob/v0.1.0/docs/wiki/Home-Assistant-Dashboard.md) and [audio guide](https://github.com/NirBY/ESP32_Smart_Clock/blob/v0.1.0/docs/wiki/Audio-And-Music.md).
